# Time Tracker para Firefox

Canal de distribuição de pacotes assinados pela Mozilla. Esta extensão não é listada publicamente na loja Firefox Add-ons.

## Instalar

1. Abra [Releases](https://github.com/pgosptf1/time-tracker-firefox/releases) e baixe o arquivo `.xpi` da versão mais recente.
2. No Firefox desktop 140 ou superior, abra `about:addons` → engrenagem → **Instalar extensão de um arquivo…**.
3. Selecione o XPI e confirme a instalação e as permissões necessárias.
4. Mantenha atualizações automáticas habilitadas. O Firefox consulta `updates.json` e instala novas versões assinadas, preservando os dados.

A primeira instalação exige confirmação. Alterações futuras de permissões também podem exigir confirmação pelo Firefox. Não remova a extensão para atualizar.

Este repositório contém somente instaladores e informações públicas de distribuição. Até a primeira publicação assinada não há instalador disponível.
